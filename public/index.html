Seberapa aman website kamu?

Masukkan alamat situsmu. Dalam beberapa detik kamu dapat laporan bernilai A sampai F, daftar celah keamanannya, dan cara memperbaiki tiap celah.

Secara default hanya pemeriksaan pasif: beberapa request biasa, tanpa serangan. Alat ini memperkenalkan dirinya lewat User-Agent.

Mode aktif (lanjutan)

Mode aktif mengirim payload uji (reflected XSS, SQL injection, open redirect). Hanya untuk target yang kamu miliki atau kamu diberi izin menguji. Perlu diaktifkan di server dengan AUDITOR_ACTIVE=1.

Apa saja yang diperiksa

Semua dilakukan dengan request biasa, sama seperti browser membuka situsmu.
